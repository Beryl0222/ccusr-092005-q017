# 儿童口腔成长随访

项目记录乳牙列、混合牙列到恒牙列期间的检查观察、生活习惯和专业判断，避免把单次焦虑等同于治疗结论。Python 模块读取脱敏样例。

在根目录执行 `python3 -m unittest discover -s tests` 可检查资料格式与闭环行为。

## 校园口腔筛查闭环（screening 包）

针对“筛查短信被误读为必须立即矫正”的场景，后端把校园提示到医院反馈连成闭环：

1. **监护同意**：学校先取得与本次活动对应的监护同意，不能跨活动复用；
2. **筛查登记**：只用最少身份信息登记牙列阶段、肉眼观察（标准化提示用语）、护理习惯和建议复核原因；筛查人员无法写入诊断或治疗方案（无对应字段，且文本中的诊断/治疗用语会被拒绝）；
3. **通知与回执**：全部监护人逐一通知并跟踪送达；家长查收后可选择医院复核、拒绝后续联系或补充既往情况；
4. **医院反馈**：医疗机构结果经监护授权后才能回传，区分无需处理、继续观察、龋病处置、专业正畸评估；同一档案只接受一份反馈。

- **五类队列**：重复筛查、转学、通知失败、监护关系变化、逾期未复核各自入队，人工跟进后关闭；
- **学校视图**：只能看到完成状态，看不到任何临床内容；
- **卫生人员视图**：去标识化的覆盖差异（仅聚合计数，默认抑制小样本格）；
- **监护人视图**：易懂的风险说明。系统不会自动把孩子导向矫正——医院反馈之前说明文字不含任何正畸/矫正表述，也不会生成相互矛盾的两份档案。

执行 `python3 -m screening.walkthrough` 可用 `fixtures/seed.json` 中现有六岁儿童和护理习惯资料演示完整链路（含一位监护人通知失败后的补达）。
